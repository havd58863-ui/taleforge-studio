# خريطة الطريق المنظَّمة — ٧ بوابات، أداة واحدة قوية لكل بوابة

> **ملاحظة صدق أولًا:** لم يصل أي ملف باسم «خريطة الطريق» في رسالتك الأخيرة (لا مرفق ولا نص).
> لذلك بنيتُ هذه الخريطة من الكود الفعلي ووثائق `docs/STORY_PIPELINE.md` و`docs/TOOLCHAIN.md`،
> وأصلحت فيها ما كان مبهمًا. إن كانت لديك نسخة مختلفة، أرسلها وأدمجها في هذه بلا إعادة بناء.

**المبدأ الحاكم:** كل بوابة لها **أداة واحدة** ، **مدخل محدد** ، **مخرج محدد** ، و**معيار قبول قابل للقياس**.
وبوابة لا تُسلِّم ملفًا صالحًا = لا تُفتح التي بعدها. بهذا يستحيل «التجاوز» أو «التداخل».

```
G0 تجهيز ─→ G1 بحث وغربلة ─→ G2 عقد ─→ G3 كتابة ─→ G4 تحرير ─→ G5 مشاهد ─→ G6 إخراج ─→ G7 نشر
   └──────────── كل بوابة تُوقف السلسلة إن لم تحقق معيار قبولها ────────────┘
```

## جدول البوابات

| # | البوابة | الأداة (واحدة) | المدخل | المخرج | معيار القبول |
|---|---|---|---|---|---|
| **G0** | التجهيز | `scripts/` + `.env` + `GET /api/tools/status` | مفاتيح/إعدادات | حالة كل خدمة | `llm`, `image_engine`, `fonts`, `kaggle` كلها معروفة بلا أخطاء |
| **G1** | هل تُبَاع الفكرة؟ | `market_research_service` + `series_service` | بيانات Kaggle (CSV) | `market_score` + `single/trilogy/open_series` + الأدلة | درجة ≥ 70 **و** `confidence = high`، وإلا تعديل الفكرة |
| **G2** | العقد الفني | `story_director_service` | الفكرة + العمر + اللغة | `StoryBrief` (٢٤/٣٢ صفحة، ميزانية كلمات، ٩ نقاط، لازمة ×٣) | `validate_brief() == []` |
| **G3** | الكتابة | LLM واحد (Ollama / HF) | العقد | `book.json` (نصوص + وصف مشهد لكل صفحة) | كل صفحة داخل ميزانية الكلمات، واللغة = لغة العقد |
| **G4** | التحرير | `editorial_review_service` | `book.json` | تقرير + `passed` | **صفر أخطاء** (٨ فحوص حاجزة) |
| **G5** | المشاهد | `image_prompt_compiler` → محرّك صور → `print_image_service` | وصف المشهد + الدستور البصري | صور PNG بمقاس الصفحة | `effective_dpi ≥ 290` + ثبات أسماء وتوكنات الشخصيات |
| **G6** | الإخراج المطبوع | `book_structure_service` + `render_picture_book_pdf` | نصوص معتمدة + رسوم | كتاب ٣٢ صفحة (٢٤ حكاية + مقدمة/خاتمة) + نشرات مزدوجة | كل صفحة حكاية **full-bleed**، والنص داخل المنطقة الآمنة، والنشرات مضبوطة |
| **G6b** | كتاب التلوين | `line_art_service` (+ VTracer) | نفس الرسوم | ٢٤ صفحة تلوين + SVGs | حبر ٠.٢–٣٠٪، أبيض/أسود نقي، ٣٠٠ dpi |
| **G6c** | الرقمي | `ebook_service` + `metadata_service` | المخطوط | EPUB + Metadata + KDP + Etsy | ملف EPUB صالح + إعلان مطابق للحدود |
| **G7** | النشر | KDP / Etsy (يدوي) | الحزمة | كتاب منشور | مراجعة بشرية للمخطوط **بصوت عالٍ** |

## من يملك الحقيقة في كل قرار (قاعدة منع التداخل)

| القرار | المالك الوحيد | ممنوع أن يقرره |
|---|---|---|
| درجة السوق والتشبّع | `market_research_service` | النموذج اللغوي، n8n، أي عقدة أخرى |
| فردي أم سلسلة | `series_service` | الحدس، النموذج |
| عدد الصفحات وميزانية الكلمات | `story_director_service` | الكاتب (يُنفّذ فقط) |
| نجاح/فشل المخطوط | `editorial_review_service` | النموذج (لا يشهد لنفسه) |
| المقاس و300dpi والكعب | `page_layout_service` + `preflight.py` | أي تقدير بصري |
| ترتيب التشغيل والجدولة | المنسّق (سكربتات أو Prefect) | — (لا يقرر محتوى) |

**الخطأ الشائع الذي يخلق التداخل:** إعادة كتابة فحص داخل المنسّق. المنسّق ينادي، ولا يحكم.

## المنسّق: بدائل n8n مفتوحة المصدر من GitHub

| الأداة | الترخيص | الشكل | لماذا/لماذا لا |
|---|---|---|---|
| **Prefect** | Apache-2.0 | Python + واجهة | ✅ **الأنسب لك**: لغتك Python أصلًا، `@flow/@task`، إعادة محاولة، جدولة، سجل تشغيل — بلا لغة جديدة |
| **Dagster** | Apache-2.0 | Python + Assets | جيد إن أردت تتبّع «الأصول» (مخطوط → PDF) ومن أين جاء كل ملف |
| **Kestra** | Apache-2.0 | YAML + واجهة | أقرب لإحساس n8n (سحب وإفلات/بياناني) بلا كود في العقد |
| **Windmill** | AGPL-3.0 | Rust + سكربتات | سريع جدًا، لكن AGPL وأثقل في التعلّم |
| **Activepieces** | MIT | TS | مفتوح فعليًا، مكتبة عُقد أصغر من n8n |
| **Apache Airflow** | Apache-2.0 | Python | أثقل من احتياجك (منصّة بيانات لا مصنع كتاب) |
| **n8n Community** | SUL (ليس OSI) | JS | مقبول داخليًا، لكن ليس «مفتوح المصدر» بالمعنى الدقيق |

**التوصية:** أبقِ التعريف الحالي (سكربتات + `Makefile`)، وأضف **Prefect** فقط عندما تصبح الكتب متوازية أو تحتاج جدولة/إشعارات. لا تُضِف أي منسّق قبل ذلك.

## ما تم إصلاحه في الخريطة

1. **بوابات لا مراحل:** كل مرحلة صارت بوابة بمعيار قبول قابل للقياس (صفر أخطاء، DPI محدد، مقاس محدد).
2. **ملكية واحدة للحقيقة:** جدول صريح يمنع أن يقرر النموذج أو المنسّق ما تملكه الأدوات.
3. **اللغة جزء من العقد:** `language` في `StoryBrief`، والنطاق EN/DE/ES، وطلب لغة معطّلة = رفض 400.
4. **كتب ثنائية اللغة كبوابة مستقلة (G6b):** كتابان مُعتمدان مسبقًا يُدمجان هندسيًا، لا ترجمة آلية وقت الإخراج.
5. **قياس لغوي صادق:** Flesch-Kincaid يُعلَّم «تقريبي» لغير الإنجليزية، و«غير مناسب» في الألمانية لا يعني مخالفة سلامة.
6. **نشر يدوي معلن:** لا أتمتة KDP/Etsy (تخالف الشروط)، والبوابة السابعة بشرية دائمًا.
